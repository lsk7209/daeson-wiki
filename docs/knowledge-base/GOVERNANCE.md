# 검수·권리·공개 정책

## 원본과 생성물

- 기사 Markdown의 `## 원문`은 canonical source입니다.
- catalog, chunks, SQLite는 재생성 가능한 파생 데이터입니다.
- AI 요약·해설·퀴즈·칼럼·슬라이드는 원문과 분리된 proposal/output입니다.
- `knowledge/`에는 복수 근거를 확인하고 사람이 승인한 문서만 둡니다.

## 검수 체크리스트

1. 기사 ID·호수·제목·원문 URL이 일치하는가?
2. 전체 기사 문맥에서 발췌문의 의미가 유지되는가?
3. 문단 ID와 콘텐츠 해시가 현재 KB 릴리스와 일치하는가?
4. OCR 필요 또는 이미지 전용 자료인지 확인했는가?
5. 직접 인용·요약·해석·추론을 구분했는가?
6. 전경 구절·인물·개념 등 연결 대상이 실제로 근거되는가?
7. 공개 또는 상업 활용에 필요한 권리를 확인했는가?

## 권리 상태

| 상태 | 허용 범위 |
|---|---|
| `internal_research_only` | 내부 검색·검토만 |
| `metadata_only` | 제목·호수·URL 등 메타데이터만 |
| `public_link_only` | 공개 링크와 메타데이터, 원문 발췌 제외 |
| `approved_excerpt` | 승인 범위의 발췌 공개 가능 |
| `restricted` | 공개 및 내보내기 제한 |

ZIP의 코드·스키마 라이선스가 기사와 이미지 원문의 권리를 부여하지 않습니다.
외부 공개, 전체 원문 재배포, 상업 이용 또는 AI 학습 데이터 제공은 별도 권리 확인
없이는 진행하지 않습니다.

현재 citation projection은 근거 발췌문을 필수로 포함하므로 `public_link_only`를
`visibility=public`로 승인하지 않습니다. 링크만 공개할 때는 발췌문을 제거한 별도
메타데이터 adapter를 사용해야 합니다.
