# 문서 자료실

이 폴더는 전경 개인 기록 프로젝트에서 참고할 원자료와 운영 문서를 보관합니다. 원본 파일명은 보존하고, 분류와 표시용 제목은 `catalog.json`에서 관리합니다.

## 폴더 구조

```text
docs/
  01_학술자료/
    01_동아도문화국제학술연토회/
    02_동아인문논단/
    03_동아인문국제논단/
  02_홍보자료/
  03_원전_기타자료/
  99_관리문서/
```

## 현재 자료

- 원자료: 18개
- 운영 문서: 1개
- 형식: PDF 16개, DOCX 2개, MD 1개
- PDF 쪽수: 5,955쪽
- DOCX 단어 수: 2019 상권 51,493어, 2019 하권 26,830어
- 본문 자동 검토: 18개 텍스트 추출 가능, `채지가.pdf` 1개 OCR 필요

## 분류 기준

- `01_학술자료`: 학술대회/논단 논문집
- `02_홍보자료`: 종단 소개, 대외 홍보 목적 자료
- `03_원전_기타자료`: 원문 성격의 보조 자료 또는 별도 검토가 필요한 자료
- `99_관리문서`: 프로젝트 운영 기록, 검증 로그, 문서 카탈로그 관리 자료

## 운영 규칙

- 원본 PDF/DOCX 파일명은 임의로 바꾸지 않습니다.
- 표시 제목, 연도, 주제, 시리즈, 권차, 권리 상태, OCR 필요 여부는 `catalog.json`에서 관리합니다.
- 본문 검토 결과는 `content-review.json`에서 관리합니다.
- 외부 공개 여부가 불명확한 자료는 `rights_status`를 `확인 필요`로 둡니다.
- 이미지형 PDF는 원본을 수정하지 않고, 추후 OCR 결과를 별도 파생 파일로 저장합니다.
- 앱 화면이나 검색에 붙일 때는 원문 전문을 복사하지 않고 메타데이터, 짧은 근거 문구, 내부 링크만 사용합니다.

## 검토 명령

```bash
npm run review:docs
npm run verify:docs
```

## 카탈로그 상태값

- `new`: 파일만 배치했고 내용 검토 전
- `reviewed`: 메타데이터와 권리 상태를 확인함
- `needs_ocr`: 이미지형 또는 텍스트 추출 불량 자료
- `rights_check`: 공개/재배포 권한 확인 필요
